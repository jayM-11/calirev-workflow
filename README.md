# CaliRev Workflow source

This is the static HTML source for the CaliRev Workflow prototype. The app's CSS and JavaScript are embedded in the HTML files; there are no separate script or dependency folders.

- `dist/index.html` — main prototype
- `dist/shop.html` — alternate shop entry page
- `dist/theme-lab.html` — visual theme samples

To preview locally, open `dist/index.html` in a browser. The main app stores its draft data in that browser's local storage.
